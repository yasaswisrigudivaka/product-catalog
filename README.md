# 🛍️ ShopEase - Product Catalog

A responsive product catalog web app built with HTML, CSS and JavaScript, using client-side routing.

## 🔗 Live Demo
https://product-catalog-ecru-beta.vercel.app

## ✨ Features
- Modular frontend with separate views (Home, Products, Product Detail, About)
- Client-side hash routing for navigation without page reloads
- Live product search and category filter
- Optimized WebP images with lazy loading
- Responsive design for mobile screens
- Deployed on Vercel

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Vercel (hosting)

## 📁 Project Structure
- `index.html`: page layout and script/style links
- `style.css`: styling
- `app.js`: product data, views and router
- `images/`: optimized product images
